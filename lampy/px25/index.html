PX25: параметры и выходной трансформатор

PX25 — триод. Накал 4 В, 2 А, прямой. Цоколь: европейский 4-штырьковый (B4). Мощность, рассеиваемая анодом, до 25 Вт. По режиму из листка для однотактного выхода нужна нагрузка около 3,2 кОм при токе покоя 62,5 мА.

Какой трансформатор и дроссель нужны

Ориентир, не гарантия

Числа посчитаны по справочным режимам: нагрузка и ток берутся из листка, индуктивность первичной обмотки — по формуле Lp ≥ Ra / (2π · 20 Гц) с запасом, коэффициент трансформации n = √(Ra / 8 Ом), КПД трансформатора не учитывается. Основа расчёта: листок лампы. Точные данные определяются по вашей схеме и режиму лампы.

Вопросы и ответы

Какой выходной трансформатор нужен для лампы PX25?

По режиму из листка для однотактного выхода нужна нагрузка около 3,2 кОм при токе покоя 62,5 мА. Это ориентир по режимам из заводских листков, а не гарантия: точные данные зависят от схемы и режима лампы.

Чем заменить лампу PX25?

По данным каталога radiomuseum.org с тем же цоколем и накалом: P27/500, LP25, CV1040, VT104_GPO, RD27AS, NR47. Режим и разводку выводов сверяйте по листку: у ламп с разными индексами они бывают разными.

Какой накал у лампы PX25?

4 В, 2 А, прямой. Обмотка накала силового трансформатора рассчитывается на это напряжение и ток на каждую лампу.

Статус данных

Данные сняты со сканов заводских листков и справочников, проверка мастером ещё не проведена. Перед заказом сверьте режим со своим листком. Режимы взяты из листок лампы: у этой лампы своего звукового режима в листке нет.

Нужен выходной трансформатор под лампу PX25? Пришлите ТЗ: схему, анодное напряжение, ток покоя и сопротивление нагрузки. Ответим, что можно сделать и в какой срок.
