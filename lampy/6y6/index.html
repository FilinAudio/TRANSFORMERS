6Y6: параметры и выходной трансформатор

6Y6 — лучевой тетрод. Накал 6,3 В, 1,25 А, косвенный. Цоколь: октальный (8 штырьков). Мощность, рассеиваемая анодом, до 12,5 Вт. По режиму из листка для однотактного выхода нужна нагрузка около 2,6 кОм при токе покоя 61 мА, мощность около 6 Вт.

Режимы из заводских листков

Какой трансформатор и дроссель нужны

Ориентир, не гарантия

Числа посчитаны по справочным режимам: нагрузка и ток берутся из листка, индуктивность первичной обмотки — по формуле Lp ≥ Ra / (2π · 20 Гц) с запасом, коэффициент трансформации n = √(Ra / 8 Ом), КПД трансформатора не учитывается. Основа расчёта: листок лампы. Точные данные определяются по вашей схеме и режиму лампы.

Вопросы и ответы

Какой выходной трансформатор нужен для лампы 6Y6?

По режиму из листка для однотактного выхода нужна нагрузка около 2,6 кОм при токе покоя 61 мА, мощность около 6 Вт. Это ориентир по режимам из заводских листков, а не гарантия: точные данные зависят от схемы и режима лампы.

Чем заменить лампу 6Y6?

Лампы с тем же цоколем и накалом по нашим данным не найдены. Замену подбираем по режиму и разводке выводов в листке.

Какой накал у лампы 6Y6?

6,3 В, 1,25 А, косвенный. Обмотка накала силового трансформатора рассчитывается на это напряжение и ток на каждую лампу.

Статус данных

Данные сняты со сканов заводских листков и справочников, проверка мастером ещё не проведена. Перед заказом сверьте режим со своим листком. Часть цифр на сканах читается неуверенно. Режимы взяты из листок лампы: у этой лампы своего звукового режима в листке нет.

Нужен выходной трансформатор под лампу 6Y6? Пришлите ТЗ: схему, анодное напряжение, ток покоя и сопротивление нагрузки. Ответим, что можно сделать и в какой срок.
