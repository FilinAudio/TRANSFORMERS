EL12: параметры и выходной трансформатор

EL12 — пентод. Накал 6,3 В, 1,8 А, косвенный. Цоколь: «стальной» немецкий (Y8A, Y10A). Мощность, рассеиваемая анодом, до 18 Вт. По режиму из листка для однотактного выхода нужна нагрузка около 3,5 кОм при токе покоя 72 мА, мощность около 8,2 Вт. Для двухтактного выхода — около 5 кОм от анода до анода, мощность около 14,5 Вт.

Ориентир, не гарантия

Числа посчитаны по справочным режимам: нагрузка и ток берутся из листка, индуктивность первичной обмотки — по формуле Lp ≥ Ra / (2π · 20 Гц) с запасом, коэффициент трансформации n = √(Ra / 8 Ом), КПД трансформатора не учитывается. Основа расчёта: листок лампы. Точные данные определяются по вашей схеме и режиму лампы.

Вопросы и ответы

Какой выходной трансформатор нужен для лампы EL12?

По режиму из листка для однотактного выхода нужна нагрузка около 3,5 кОм при токе покоя 72 мА, мощность около 8,2 Вт. Для двухтактного выхода — около 5 кОм от анода до анода, мощность около 14,5 Вт. Это ориентир по режимам из заводских листков, а не гарантия: точные данные зависят от схемы и режима лампы.

Чем заменить лампу EL12?

Лампы с тем же цоколем и накалом по нашим данным не найдены. Замену подбираем по режиму и разводке выводов в листке.

Какой накал у лампы EL12?

6,3 В, 1,8 А, косвенный. Обмотка накала силового трансформатора рассчитывается на это напряжение и ток на каждую лампу.

Статус данных

Данные сняты со сканов заводских листков и справочников, проверка мастером ещё не проведена. Перед заказом сверьте режим со своим листком. В листках есть расхождения: накал, крутизна, внутреннее сопротивление, мощность на второй сетке, сопротивление в цепи сетки. Режимы взяты из листок лампы: у этой лампы своего звукового режима в листке нет.

Нужен выходной трансформатор под лампу EL12? Пришлите ТЗ: схему, анодное напряжение, ток покоя и сопротивление нагрузки. Ответим, что можно сделать и в какой срок.
